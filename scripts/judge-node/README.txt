机创OJ 本地判题节点自动安装器

使用方法：
1. 解压整个 ZIP，不能只打开压缩包直接运行。
2. 双击“安装判题节点.cmd”，允许 Windows 管理员授权。
3. 选择一个至少剩余 25GB 的本地磁盘或文件夹。
4. 保持电脑开机联网，等待管理后台显示“在线可用”。

安全说明：
- 安装器创建独立 Ubuntu 22.04 虚拟机，不使用电脑原有 Ubuntu。
- 虚拟机不共享 C/D/E 盘、剪贴板、USB 或文件夹。
- 虚拟机采用 NAT，Judge0 不开放任何入站端口；判题槽只通过出站长轮询领取任务。
- 只有经一次性配对的节点能连接机创OJ；配对信息两小时后失效且只能使用一次。
- 学生程序不能联网，并受到 CPU、内存、进程数和输出大小限制。
- 只能在可信管理员或老师控制的电脑上安装，节点所有者仍可能通过系统最高权限接触运行中的代码和测试点。

安装包中不包含管理员密码、GitHub Token 或 Cloudflare Token。
