机创 OJ Claude 本机批改助手
============================

使用方法：
1. 请先安装 Node.js，并确认命令行可以运行 node --version。
2. 请先安装 Claude Code CLI、完成登录，并确认命令行可以运行 claude --version。
3. 双击 start-claude-grading-helper.cmd。
4. 保持打开的命令窗口运行，然后回到 https://jc-oj.online 管理后台。
5. 点击“检测助手”；显示“已连接”后即可使用 Claude 一键批改。

同一道题的答案会自动分批，并最多同时启动 6 个互相独立的 Claude 会话；任一会话完成后会立即保存结果并开始下一个，不等待其余会话。
多个“Claude 重新评分”请求也会进入同一队列：最多 6 个同时运行，其余自动等待，不会无限增加并发。

安全说明：
- 助手只监听本机 127.0.0.1:37841，不会向局域网开放端口。
- 助手只接受来自 https://jc-oj.online 的浏览器请求。
- 临时批改文件在每次任务结束后自动删除。
- 关闭命令窗口即可停止助手。

浏览器禁止网页自动运行刚下载的程序，因此首次使用必须由您手动解压并双击启动文件。
